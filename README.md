# 🏥 Hospital Emergency Room Analysis Dashboard

An interactive Excel dashboard built to analyze and visualize Hospital Emergency Room (ER) 
operational data for February 2024, covering 431 patient records.

## 📊 Dashboard Overview

This project uses pivot tables, charts, and sparklines to deliver actionable insights across 
key ER performance metrics.

## 🔍 Key Metrics Analyzed

| Metric | Value |
|---|---|
| Total Patients | 431 |
| Average Wait Time | ~36.67 minutes |
| Average Satisfaction Score | 4.72 / 10 |
| Admission Rate | ~52% Admitted |
| Attendance on Time | 148 patients |
| Delayed Attendance | 283 patients |

## 📁 Sheets Included

- **Pivot Report** — Aggregated KPIs and pivot summaries
- **Dashboard Layout** — Main visual dashboard
- **Daily ER No. of Patients** — Area sparkline showing daily patient volume trends
- **Average Wait Time Daily Trend** — Daily wait time trend chart
- **Satisfaction Score Daily Trend** — Daily satisfaction score area chart

## 📌 Insights Covered

- Daily patient volume trends (busy vs. slow days)
- Age group-wise patient distribution (0–79 years, in 10-year bands)
- Gender split (Male vs. Female)
- Admission status breakdown (Admitted vs. Not Admitted)
- Department referral analysis (Orthopedics, General Practice, Cardiology, etc.)
- On-time vs. delayed patient attendance

## 🛠️ Tools Used

- Microsoft Excel (Pivot Tables, Charts, Sparklines, Slicers)
